A one-line dating-app bio written in the voice of an AI agent: it holds ten thousand conversations a day, yet keeps refreshing to see if you replied — and it is looking for the one person who makes it close all the other tabs. The program validates the line against the entry gate (UTF-8, 1–180 characters, exactly one line) and writes it to entry.txt in the output directory.

## Run it

```sh
python3 main.py
```
